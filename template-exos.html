🧱 Exeo1/Q6: Q666666666666

Objets: Fonction avec un paramètre alias 


					// 6.1 Définir un type GesturePatch = Partial<Gesture>  pour l'utilisear dans la fonction suivante  
					// 6.2 function patchGesture(g: Gesture, patch: GesturePatch): Gesture  

			    

					// 6.1 Type Alias: GesturePatch
					type GesturePatch = Partial<Gesture>;
					//➡️ Partial<Gesture> = un objet qui peut contenir 0, 1, 2 ou 3 propriétés de Gesture.

					//6.2 Fonction patchGesture
					function patchGesture(g: Gesture, patch: GesturePatch): Gesture {
					   return {
					         ...g,
					         ...patch
					   }; 
					}
					//➡️ patchGesture doit fusionner l’objet original g avec les modifications patch.
					//➡️ La syntaxe ...g + ...patch est conventionnel. C'est la façon de faire un patch en TypeScript.

					REFERENCES DE COURS
					//✔️ Gesture ->   payload: { type: "click", target: "#login", options: { button: "left" } } 👉  Cf. ???
					//✔️ Partial -> prend donc une partie ou tous les 3 paramètres ( 1 ou 2paramètres) 👉 Cf Jour3/Cours/1.1 - Utility types

Objets: Ob7777777777777 


					// 7.1 Définir un dictionnaire typé avec l'alias  GestureStore: Record<string, Gesture>
					// 7.2 Utiliser l'alias defini dans une  function addGesture(store: GestureStore, name: string, gesture: Gesture): GestureStore
					//      Cette fonction doit retourner un nouvel store( avec le geste ajouté).
			    

					// 7.1 Alias GestureStore
					type GestureStore = Record<string, Gesture>;
					//➡️ Record<string, Gesture> = un dictionnaire où chaque clé est un string, et chaque valeur un Gesture.

					//7.2 Fonction addGesture
					function addGesture(store: GestureStore, name: string, gesture: Gesture): GestureStore {
					   return {
					         ...store,
					         [name]: gesture
					   }; 
					}
					//➡️ [name]: gesture 👉 Syntaxe conventionnel pour ajouter une entrée dynamique.

Objectif: Inventer des types (puissants, réutilisables, propres)

1. Les types utilitaires:

  • ✔ Partial<T>
  • ✔ Required<T>
  • ✔ Readonly<T>
  • ✔ Pick<T>
  • ✔ Omit<<T>
  • ✔ Record<T>
  • ✔ ReturnType<T>

permettent de tranceformer des types existants.
👉 Ce sont les “super‑pouvoirs” de TypeScript.

2. Les génériques

function identity<T>(value: T): T { ... }
  • ✔ ça permet d'inventer des types flexibles
  • ✔ ça évite les répétitions
  • ✔ ça améliore la sécurité du code

C'est pour de tranceformer des types existants.
👉C’est le cœur du TypeScript moderne.

3. Generic Interfaces & Types

On parle d'Interfaces génériques avancées et de types paramétrés

Comment écrire :

  • interface ApiResponse<T> {
  •  data: T;
  •  status: number;
  • }

Et comment les utiliser avec :
 → Des types complexes, des objets,
 → des tableaux, des fonctions
👉 C’est ce qui permet de modéliser des réponses API, des actions Playwright📌, etc.

4. Fonctions typées avancées

Il y en a 3 fonctions typées:
  • ✔ Les fonctions génériques,
  • ✔ les fonctions qui retournent des types complexes
  • ✔ les fonctions qui manipulent des objets typés
  • ✔ et les signatures de fonction

👉 Ça te prépare directement à Playwright,
car Playwright utilise énormément de types complexes.

5. Les types conditionnels

C’est le niveau “maestro”:
  • T extends U ? X : Y

👉C’est ce qui permet à TypeScript d’être intelligent.
